Опыт участия в олимпиаде по информационной безопасности

Призёр регионального этапа олимпиады по информационной безопасности.

Типы задач, с которыми работал:

криптография;
анализ сетевого трафика;
поиск уязвимостей;
логическое моделирование атак.

Данный опыт сформировал системное понимание принципов защиты информации и анализа угроз.
